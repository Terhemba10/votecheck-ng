# Demo video script (about 2½ minutes)

Record the screen at http://localhost:3000, or at your Render link once it's live. Speak slowly. Each section shows roughly how long to spend on it.

## 1. Opening (0:00–0:15)
**Show:** the home page.
**Say:** "This is VoteCheck NG, a nonpartisan tool for Nigerian elections. It does two things: it helps voters in their own language, and it helps observers check that polling-unit results add up."

## 2. Voter help in five languages (0:15–0:55)
**Do:** click "I lost my PVC. What can I do?"
**Say:** "Voters get clear answers from a built-in voter guide, always pointing to INEC's official site for dates and locations."
**Do:** switch Language to **Yorùbá** and click a suggested question. Then switch to **Hausa** and ask another.
**Say:** "The same answers are available in Pidgin, Hausa, Yorùbá and Igbo, and they work even without an AI service."
**Do:** type "Who should I vote for?"
**Say:** "It never tells anyone who to vote for. It explains how to compare candidates fairly instead."

## 3. Result checker (0:55–1:50)
**Do:** open the **Result checker** tab.
**Say:** "Observers upload polling-unit results as a CSV. Eight fixed rules check every unit."
**Do:** point to the summary tiles, then the first rows of the flagged table.
**Say:** "Here, polling unit 01-003's paper sheet shows 149 votes for Party B, but IReV shows 194. That's flagged critical. Unit 02-003 has 385 votes cast but only 350 accredited voters: over-voting. Unit 01-004 has no IReV upload at all."
**Say:** "A flag means 'verify this', not 'fraud'. The same data always gives the same flags, and every rule is covered by automated tests."
**Do:** press **Write report**.
**Say:** "Then it writes a plain-language observer report with verification steps."

## 4. Responsible AI (1:50–2:20)
**Say:** "Our principle: rules decide the flags, people decide the outcome, and AI only explains. The server re-runs every check itself, stores no personal data, and works even if the AI service goes down. It's clearly marked as an independent tool, not an official INEC site."

## 5. Close (2:20–2:35)
**Show:** the home page again.
**Say:** "VoteCheck NG: know how to vote, and check that results add up. Thank you."

### Recording tips
- On Windows, **Win + Alt + R** records the active window with the Xbox Game Bar. **Clipchamp**, built into Windows 11, can trim the video.
- Zoom the browser to 125% so the text is readable.
- Before recording, press **Reload sample** so the flags match the script.
